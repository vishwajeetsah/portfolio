# Vishwajeet Sah — Portfolio

Personal portfolio of **Vishwajeet Sah**, a law student building technology for
access to justice.

**Live site:** https://vishwajeetsah.github.io/portfolio/

## What's inside

- **Law that reaches people** — introduction: 4th-year B.A. LL.B. (Hons) student
  at Dr. Harisingh Gour Vishwavidyalaya (Central University), Sagar; Para Legal
  Volunteer with DLSA Sagar; Google Campus Ambassador 2026
- **From science to law** — the PCMB-to-law journey
- **The internship journey** — Ministry of Law and Justice (New Delhi), DLSA
  Sagar, District Consumer Forum Sagar, and the office of Sr. Advocate Pradeep
  Rai (Supreme Court)
- **Featured project** — LegalAid India, the free legal aid eligibility checker
  under Section 12 of the Legal Services Authorities Act, 1987, with a live
  demo of the tool
- **Beyond the classroom** — NCC (Army), NSS, Viksit Bharat Youth Parliament,
  RBI National Quiz
- **Skills & education**, and a contact section — open to internships, research
  and collaborations

## Tech stack

- Single-file static site: HTML, CSS and JavaScript in `index.html`
  (no build step, no framework)
- Hosted on GitHub Pages from this repository

## Local preview

```bash
git clone https://github.com/vishwajeetsah/portfolio.git
cd portfolio
python3 -m http.server 8000
# open http://localhost:8000
```
